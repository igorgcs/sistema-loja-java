🛒 Sistema de Loja em Java

Projeto desenvolvido em Java com o objetivo de praticar conceitos de Programação Orientada a Objetos (POO).

📚 Conceitos praticados
Classes e objetos
Construtores
Métodos
Organização do código
Manipulação e exibição de produtos

💻 Funcionamento

Ao iniciar o sistema, uma saudação é apresentada ao usuário e, em seguida, são exibidos os produtos disponíveis em estoque.

🛠️ Tecnologias

Java
IntelliJ IDEA

🎯 Objetivo

Projeto desenvolvido como parte dos meus estudos em Java e Programação Orientada a Objetos.
